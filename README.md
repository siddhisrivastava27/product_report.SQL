# Product Report | SQL Data Analytics Project

## Project Overview
This project focuses on analyzing product data using SQL to generate a comprehensive product report. The report consolidates key product metrics and performance insights to understand product sales, revenue contribution, and purchasing patterns.

The project combines product information with transaction data to calculate important KPIs, evaluate product performance, and identify high-, mid-, and low-performing products based on revenue.

## Project Objectives
- **Consolidate Product Information:** Gather essential product details, including product name, category, subcategory, and cost.
- **Segment Products by Revenue:** Categorize products into high-, mid-, and low-performing segments based on revenue.
- **Aggregate Product Metrics:** Calculate total orders, sales, and quantity sold to evaluate product performance.
- **Analyze Customer Retention and Lifespan:** Examine customer purchasing behavior and lifespan in relation to product sales.
- **Calculate Key Performance Indicators (KPIs):** Analyze the most recent sale date, average order revenue, and other relevant product metrics.
- **Generate a Product Report:** Transform raw data into a structured report for product performance analysis.
